Zero-Leakage Guarantee

Privacy-by-Design Architecture

PulseVerse was built under strict ethical protocols. Biometric sensing requires absolute trust, and PulseVerse ensures zero camera frames or vitals leave your local computer.

✓
Volatile RAM Processing Only: Camera frames exist solely in volatile system memory during optical rPPG extraction and are immediately discarded.
✓
Telemetry Disabled: SmartSpectra SDK initialized with enableTelemetry: false. No diagnostic usage telemetry is sent to Presage.
✓
Electron Multi-Process Hardening: Strict context isolation, renderer sandboxing enabled, and Node integration disabled.
✓
Non-Medical Informational Tool: For general wellness and artistic biofeedback only. Does not diagnose diseases or score mental anxiety.

Developer Setup

Running Locally

1. Clone & Install Dependencies
git clone https://github.com/GenX0Gravity/PulseVerse-Your-Body-Your-Universe.git
cd PulseVerse-SmartSpectra-Human-Sensing
npm install
2. Configure Developer License Key
cp .env.example .env
# Add PRESAGE_API_KEY=your_key_here
3. Launch Live Electron Desktop App
npm run dev

System & Hardware Requirements

  • ▸ Operating System: Windows 10/11 x64 (Native C ABI package included)
  • ▸ Webcam: 720p @ 30 FPS USB or built-in webcam with consistent lighting
  • ▸ GPU: WebGL 2.0 capable graphics card for Three.js shaders
  • ▸ SDK Version: @smartspectra/node-sdk v3.5.0 with koffi pure-ABI
  • ▸ Node Runtime: Node.js 20+ / Electron 33+
Simulated Demo Mode Included: No camera or API key? Switch to Demo Mode (`M` key) at any time to experience the complete audio-visual cosmos powered by physiological mathematical models.
